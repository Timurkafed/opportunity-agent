# План: перевод Opportunity Agent в облако

Составлен 20.11.2026. Цель: бот и вся работа над ним идут без ноутбука,
владелец следит и подсказывает с телефона.

## 1. Что есть сейчас

- Бот готов и работает: ~40 источников (30 Telegram-каналов, 10 сайтов), отбор через
  бесплатный Gemini, дайджест в Telegram, кнопки 👍/👎, память в `state/`.
- Запускается **только с ноутбука** (Планировщик Windows, 9:00 и 18:00).
  20.11 утренний запуск оборвался (код 0xC000013A, процесс убит при выключении/сне),
  дайджест не пришёл. Это и есть главная проблема.
- GitHub Actions заблокирован из-за оплаты на аккаунте. Платить не вариант.
  GitLab-вариант подготовлен (`.gitlab-ci.yml`), но аккаунт не заведён.
- Репозиторий `Timurkafed/opportunity-agent` **публичный**: память бота (`state/`) видна всем.
- Gemini на бесплатном тарифе постоянно отвечает 429/503, запуск идёт 3–5 минут.

## 2. Как будет устроено

Две разные вещи переезжают в облако Claude Code (claude.ai/code), оба входят в подписку Pro,
отдельно за сервер не платим.

| Что | Где | Как |
| --- | --- | --- |
| **Работа бота** (дайджест 2 раза в день) | облачная задача по расписанию Claude Code | каждый запуск: `python -m agent.main`, сохранить `state/` в репозиторий, при ошибке написать в Telegram |
| **Разработка** (правки, новые источники, функции) | облачная сессия Claude Code на этом репозитории | владелец пишет задачу с телефона (приложение Claude, вкладка Code), Claude делает сам |

Облачная среда `opportunity-agent`: полный доступ в сеть (источники разбросаны по десяткам сайтов),
переменные `TELEGRAM_BOT_TOKEN` и `GEMINI_API_KEY`.

Расписание: `CRON_TZ=Asia/Almaty 7 9,18 * * *` (9:07 и 18:07; ровно на :00 облако запускает с опозданием).

## 3. Этапы

### Этап 0. Подготовка, нужен владелец (≈10 минут, один раз)
См. раздел 6. Пока он не сделан, бот продолжает работать с ноутбука.

### Этап 1. Безопасный переезд (без двойных дайджестов)
1. Защита от двойного запуска: перед работой бот берёт свежую память из репозитория и
   пропускает запуск, если другой запуск уже прошёл за последние 4 часа. Нужно, пока
   работают оба варианта (ноутбук и облако), иначе придут два дайджеста и собьётся счётчик кнопок.
2. `run_digest.ps1`: `git pull` перед запуском, чтобы ноутбук видел память облака.
3. Сообщение в Telegram, если запуск упал (сейчас ошибки видно только в логе на ноутбуке).
4. Создать облачную задачу по расписанию, прогнать вручную, сверить дайджест.
5. Три удачных облачных запуска подряд, затем отключить задачу в Планировщике Windows.
   Скрипт на ноутбуке оставить как запасной, запуск руками.

### Этап 2. Надёжность
1. Меньше запросов к Gemini: больше материалов в одном запросе, повтор только недоделанного.
2. Если Gemini отказал полностью, отбор делает сам Claude внутри облачной задачи
   (по тем же правилам из `criteria.md`). Это тратит лимиты Pro, поэтому только как запасной путь.
3. Проверка источников раз в неделю: какой канал или сайт перестал отдавать посты
   или три недели не даёт ни одной годной возможности. Отчёт в Telegram.
4. Тесты на сбор и склейку дублей, чтобы правки не ломали бота молча.

### Этап 3. Качество отбора
1. Учесть первые оценки 👍/👎 и переписать `criteria.md` под реальные предпочтения.
2. Поиск новых источников: Telegram-каналы вузов и сообществ Алматы и Астаны,
   кейс-чемпионаты, акселераторы. Каждый новый источник проверять неделю перед включением.
3. Сделать репозиторий приватным (память бота сейчас публичная).

### Этап 4. Дальше (из `ideas-later.md`, по одному)
1. Страница-лента всех найденных событий по датам.
2. Кнопка «Подать»: черновик ответов на анкету и ссылка на Google Form с заполненными полями.
   Ограничение: бот без постоянного сервера видит нажатие только при следующем запуске
   (до 9 часов). Мгновенный ответ потребует постоянного бесплатного хостинга (например,
   Cloudflare Workers), это отдельное решение.
3. Дополнительные подборки: вакансии, стипендии, необычные события.

## 4. Как я работаю без владельца

- Решения принимаю сам. Всё, что нужно от владельца, записываю в раздел 7 этого файла и
  отправляю одним сообщением в Telegram через этого же бота с пометкой «🤖 Claude ждёт тебя».
  Работу, которая от этого зависит, откладываю и иду дальше.
- Каждое изменение: проверка запуском `--dry` и `--no-send`, затем коммит в `main`
  с понятным описанием. Ломающие изменения сначала в ветку `claude/...`.
- Никогда: не ввожу пароли и ключи за владельца, не оплачиваю, не регистрирую его
  на событиях, не пишу людям от его имени.

## 6. Что сделать владельцу (один раз)

1. **Дать Claude доступ к репозиторию.** Открыть https://github.com/settings/installations,
   у приложения **Claude** нажать **Configure**, в «Repository access» добавить `opportunity-agent`, **Save**.
   Если Claude в списке нет, поставить его отсюда: https://github.com/apps/claude.
2. **Создать облачную среду.** На https://claude.ai/code открыть выбор среды → **Add environment**:
   - Name: `opportunity-agent`
   - Network access: **Full**
   - Environment variables: две строки из файла `.env` на ноутбуке
     (`TELEGRAM_BOT_TOKEN=...` и `GEMINI_API_KEY=...`). Ключи вставляет владелец сам,
     Claude ключи в чужие поля не вводит.
3. **Приложение Claude на телефоне** (iOS/Android), вкладка **Code**, включить уведомления.
   Там видны облачные сессии и задача по расписанию.
4. Не обязательно: если когда-нибудь разблокируете GitHub Actions, бот переедет туда за пару минут.
