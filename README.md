# Opportunity Agent

Telegram-бот, который дважды в день (9:00 и 18:00 по Алматы) сам просматривает ~40 источников
(Telegram-каналы и сайты), отбирает через Gemini хакатоны, митапы, кейс-чемпионаты, форумы и прочие
возможности и присылает короткий дайджест. Под каждой возможностью кнопки 👍/👎 — они влияют на следующий отбор.

Всё бесплатно: Gemini API (бесплатный уровень), Telegram Bot API. Запуск по расписанию: облачная задача Claude Code
(`cloud_run.sh`), запасные варианты: ноутбук (`run_digest.ps1`, Планировщик Windows) и GitLab (`.gitlab-ci.yml`).
GitHub Actions заблокирован из-за оплаты, `digest.yml` выключен.

## Что где лежит

| Файл | Зачем |
|---|---|
| `criteria.md` | Правила отбора. Gemini читает этот файл как инструкцию — меняйте текст, меняется поведение. |
| `config/sources.json` | Список источников для бота. Новый Telegram-канал = дописать его имя в список `telegram`. |
| `sources.md` | Тот же список с пояснениями для человека. |
| `ideas-later.md` | Идеи на потом. |
| `agent/` | Код: `collect.py` сбор, `llm.py` Gemini, `tg.py` Telegram, `main.py` весь запуск. |
| `state/` | Память бота: что уже видел, что присылал, ваши 👍/👎. Обновляется сама после каждого запуска (`agent/gitstate.py`). |
| `docs/` | Планы: `fix-plan.md` (надёжность), `cloud-plan.md` (переезд в облако). |
| `tests/` | Проверки без сети: `python -m pytest tests`. |
| `.github/workflows/digest.yml` | Расписание. |

## Секреты (Settings → Secrets and variables → Actions)

- `TELEGRAM_BOT_TOKEN` — токен от @BotFather.
- `GEMINI_API_KEY` — ключ с aistudio.google.com.
- `TELEGRAM_CHAT_ID` — необязательно: бот сам запомнит чат, когда вы нажмёте Start.

## Ограничения, о которых стоит знать

- Нажатия 👍/👎 бот читает при следующем запуске, поэтому «Учтено» появляется не сразу.
- GitHub запускает расписание с опозданием 5–30 минут — это нормально.
- Telegram хранит нажатия 24 часа; между запусками максимум 15 часов, так что ничего не теряется.

## Запуск на своём компьютере (для проверки)

```
python -m agent.main --dry       # только сбор, ключи не нужны
python -m agent.main --no-send   # сбор + Gemini, дайджест печатается в консоль (нужен GEMINI_API_KEY)
python -m agent.main --force     # настоящий запуск, даже если другой был меньше 4 часов назад
python -m pytest tests           # проверки
```

Один настоящий запуск = `python -m agent.main` (сам берёт свежую память из GitHub и пропускает запуск,
если другой был меньше 4 часов назад) + `python -m agent.gitstate <кто>` (сохраняет память в GitHub).
